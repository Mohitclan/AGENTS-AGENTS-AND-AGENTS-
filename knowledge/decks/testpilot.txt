=== PAGE 7 ===
 Honest results
Only real site bugs count against a site’s health
Site bug
A check that ran and failed. Counts against health.
Blocked
A CAPTCHA stopped it. Reported, never bypassed.
Warning
Works, but isn’t what it says: a Privacy link opening Contact.
Tool error
TestPilot’s own trouble. Never blamed on the site.
Test issue
The test is wrong, not the site: needs maintenance.
Not run
Site down or login failed: the run stops and says why.
Rule one: a false pass is worse than a false fail. A test never passes unless its main check really ran.
