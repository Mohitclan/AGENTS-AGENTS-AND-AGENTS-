## 1. What Deplexo is

Deplexo is a hosted platform that deploys apps from a Git repository: its own About page calls it "a managed Platform as a Service for deploying GitHub repositories as secure containers", its homepage headline is "From git push to a live app", and its GitHub org describes it as a platform for deploying and managing websites, APIs and bots. It has a free tier with no card, runs each app in an isolated container in one region (EU, Germany), and offers a CLI, docs, starter apps and an MCP link for AI agents. Its About page gives an address in Ahmedabad, Gujarat, India; its GitHub org says Bengaluru, India. No founder, team or company registration is published anywhere I opened. [https://deplexo.com/about ; https://deplexo.com ; https://github.com/Deplexo]

## 2. Product features as they describe them

Each bullet is Deplexo's own claim on its own page, not tested by us.

- Deploy from GitHub, GitLab, Bitbucket and Codeberg over OAuth, with no personal access tokens. [https://deplexo.com]
- Builds from your Dockerfile, or detects the framework; stacks named: Node.js, Python, Go, Ruby, Rust, Java, PHP, Elixir, static sites, any Dockerfile. [https://deplexo.com ; https://deplexo.com/about]
- Automatic HTTPS subdomain once the first deploy is healthy; custom domains with DNS verification. [https://deplexo.com ; https://docs.deplexo.com]
- Isolated container per app with CPU, memory, disk and bandwidth caps by plan; build and container logs in the dashboard; rollback to a previous successful build. [https://deplexo.com]
- Signed outgoing webhooks for deployment events, including Discord and Slack. [https://deplexo.com]
- MCP integration so Claude Code, Cursor and other MCP clients can deploy, check progress and read logs. [https://deplexo.com ; https://docs.deplexo.com]
- A CLI (Go; Linux, macOS, Windows) to log in, list and create apps, deploy, view deployments and follow logs; plus a User API for scripts or CI and a `deplexo.yaml` config file. [https://github.com/Deplexo/cli ; https://docs.deplexo.com]
- Stated limits: one container instance per app, no autoscaling, no managed databases, one persistent volume per app, read-only container filesystem. [https://deplexo.com]
- Plans as listed (seen 2026-11-04): Free $0 (1 app, 128 MB, 0.25 CPU); Starter $5 per 30 days (3 apps); Pro $10 per 30 days (6 apps); Business custom. Starter and Pro do not renew automatically. [https://deplexo.com/plans] (Not needed for the demo; recorded because the page dates it.)
- Content they publish: four blog posts, all dated "September 2026" with no day, on free hosting, Heroku alternatives, a free Discord bot deploy guide and Docker hosting comparison. [https://deplexo.com/blog]
