# MotionRepo battlecard: first segment

Internal use only. 2026-10-30. Segment (hypothesis): launch-active, founder-led Indian software product startups, about 2 to 20 people, launch or major release within 60 days.

Ranking is judgment (hypothesis); no prospect has said any of these. Answers are drafts: the fact sheet says objection answers need human approval [NEEDS APPROVAL]. Order: budget is the open risk; founders search first; code access can block a deal; proof is cheap to test; payment bites after the trial.

## 1. "₹3,199 a month plus GST is a lot for one launch. Why not a freelancer or do it ourselves?"
- Say: Starter is ₹3,199/month + 18% GST, billed monthly, no yearly plan. Free trial: 14 days, 6 credits, no card. Six credits cover a teaser (2), both PDFs (1) and a one-minute walkthrough (3).
- Weak: we have no freelancer price, so don't compare. Remotion is free for companies of up to 3 people (checked 2026-10-30), but needs a developer's time and has no PDFs. A team of up to 3 with a spare developer may be better off with it. Trial videos are 720p with a watermark.
- Discount: none. Any request is [NEEDS APPROVAL]. Cancellation terms: [NEEDS APPROVAL].
- Next step: "Start the free trial on one repo and judge the teaser."

## 2. "RepoClip does this for $24 a month. Why you?"
- Say: RepoClip Starter is $24/month (checked 2026-10-30) and has a watermark. You get a sales PDF and a technical PDF from the same run, plus 1080p with no watermark from Starter, in rupees, by invoice, plus 18% GST.
- Weak: we have not converted dollars to rupees, so never say "cheaper". Say nothing either way about RepoClip's PDFs; if asked, point them to RepoClip's site. RepoClip can be tried without a GitHub account, and has a public API and GitHub Action for video on every release. It looks card-payable; we are invoice-only. If you want card payment today or no GitHub account, RepoClip may suit you better.
- Next step: "Start the free trial on one repo and compare it with RepoClip."

## 3. "My code goes to a third party? Do you have SOC 2?"
- Say: no SOC 2, ISO 27001, SSO, two-factor sign-in or activity log. Parts of the code go to Anthropic's Claude. The GitHub App has read-only access and MotionRepo never writes to your repo. Video sessions run with "guard rails, not a sandbox".
- Self-hosted runs on your servers with your own Claude account, on request. It still uses Claude. Price and terms: [NEEDS APPROVAL].
- Not known: which parts of the code are sent, and retention. Check with the team.
- Next step: offer a public repo URL for the trial. If they need SOC 2 or SSO, stop.

## 4. "Who else uses it? Show me it works on a real product."
- Say: there are no customers, quotes or metrics to share. Video is motion graphics from the code, not a recording of your live interface.
- Weak: if they need the real UI on screen, Arcade, Supademo or Loom show it. Output quality is untested by us. Filmed walkthrough: do not offer.
- Next step: ask them to run one trial teaser and reply with what they think.

## 5. "Can I pay by card or UPI? Why GitHub only?"
- Say: payment is by invoice today; pay the invoice and the plan changes. Card and UPI are "coming"; no date.
- Weak: it reads code through GitHub. No GitHub, no trial. If their code is not on GitHub, stop: we can't serve them yet.
- Next step: confirm they are on GitHub and can pay by invoice, then start the trial.
