## Why Repowise is an ESCALATE

`knowledge/company.md` line 39 says never contact competitors. `knowledge/products/motionrepo.md` line 149 and `knowledge/competitors/motionrepo.md` line 87 list "Mintlify and DeepWiki (indirect, docs from code)". Repowise publishes the following:

- "repowise vs DeepWiki: Self-Hosted Codebase Docs That Stay Fresh", by its co-founder, updated 29 Oct 2026 (https://repowise.dev/blog/comparisons/repowise-vs-deepwiki).
- "Generated docs ... Documentation that rebuilds itself on every commit" (https://repowise.dev/features).
- A wiki where "Every commit updates the pages it touched" (https://repowise.dev/features/wiki).

**This is a question, not a finding of breach.** Repowise sells codebase intelligence for AI agents, and it makes no sales PDFs or videos. A person could reasonably say it is not a competitor, but the policy does not say whether "competitors" includes indirect ones. Only the technical PDF overlaps. The answer decides whether this file should exist, so it comes before any redraft.

**This should have been caught earlier, and by me.** The lead rubric asks about competitors, and T-20261030-06 r3 scored "No disqualifier". I did not compare what Repowise makes against the competitor categories.
