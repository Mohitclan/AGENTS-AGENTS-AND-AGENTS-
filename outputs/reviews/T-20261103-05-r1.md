## 5. Nurture as a `cold-email` section

**The choice is right.** `cold-email` already claims nurture (line 3), and it is loaded by exactly the three agents that can start a sequence. That means "one sequence per person" reaches all of them, which a marketing-only skill would not.

**But the text must fit its host, and in four places it doesn't:**

1. **It inherits rules it can't meet.** Line 16 says the Never and Compliance sections that follow apply to it. But `cold-email` Compliance requires a "business contact published by the company or person". The send-risk grade (`cold-email` lines 117-119) marks an unclear or unpublished contact Red, "Don't draft". A sign-up's address is neither published nor a business contact, so by the host's own text every nurture email fails compliance. The "Two to three" follow-up cap (`cold-email` line 103) is also silent on whether it binds a nurture plan (fix 1).
2. **Its steps conflict with each other.** Line 28 keeps "an ID from the product's records, not an address". Line 29 then has the agent check `pipeline/suppression.jsonl` and the never-contact list, including "a personal address". The suppression list keys only on an email or domain (`pipeline/lead-schema.md` line 105, `scripts/leads.mjs` line 256), so an agent holding only an ID can't run either check. The same applies to line 39's suppress request. Line 48 already gives the per-step check to a person; the pre-draft check needs the same owner (fix 2).
3. **"You can't run it" is wrong for two of the three loaders.** Line 39 says to suppress at once with `node scripts/leads.mjs suppress`, then "you can't run it, so ask the coordinator in your RESULT". Marketing has no shell, but outreach and sales do. Hard rule 7 says to suppress "at once" (fix 3).
4. **The Taken list overstates.** The Sources note (line 58) claims "a value ladder with rotating touches", which the text doesn't carry (fix 4).

The rest agrees with `cold-email`:
- the opt-out line;
- the 120-word body;
- one call to action;
- no invented urgency (it is consistent with `cold-email` line 127, and stricter);
- discounts and extensions going to the approvers.
