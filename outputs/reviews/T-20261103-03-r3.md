### Residual gap (for the human)

`readAgent()` in `scripts/_agents.mjs` (lines 37-52) only reads `key: value` lines and `- item` lines. Any other indented continuation line is skipped silently. So a `tools` value that spans lines as a flow list or a `>`/`|` block scalar hides its later entries from the test. Claude Code parses real YAML and would grant those entries.

- No agent file uses these forms today. The docs' own examples are single-line strings or block lists.
- The repo's other tooling, such as `fallbacks.mjs`, uses the same parser, so it would also misread such a file.
- So this is a guard against unusual future edits, not a live hole. I don't think it's worth reopening the task. If someone wants it closed, the simplest guard is a test assertion that every agent file's `tools:` value sits on one line or is a block list.
- It's also worth adding one line to Risk 2, because "rejects the bad entry in any position" currently reads as covering every YAML form.
