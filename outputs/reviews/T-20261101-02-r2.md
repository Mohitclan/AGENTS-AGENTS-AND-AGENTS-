### "Push is main-branch only" (line 97): true, with looser wording than the code

- Lines 88-94 of `WebhookController.ts` hold the comments and the call. The test itself is `src/billing/billing.ts:245-249`: `branch === readMetadata(repository)?.defaultBranch`.
- So "main" means the repository's default branch, whatever it is called. A repository whose default is `master` regenerates on a push to `master`.
- "The repository's default branch or a push to main" reads as two branches when it is one. All documents paths use the default branch, including Regenerate (`regenerate.ts:23`).

The site's "push to main" is the same shorthand, and the point at line 97 survives: documents follow the default branch, while video takes a chosen branch. No proposed wording uses "main" (correction 4).
