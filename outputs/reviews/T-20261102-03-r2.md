### Hover probe (method)

- **Probe:** `hover2.mjs`, a scratch file outside the repo. It moves the mouse to each row, checks `:hover` matched, and then measures every text-bearing element in the row. The measure is computed colour against the composited background.
- **Transitions:** the probe injects `transition:none` so the end state is read. Headless Chrome hadn't advanced the 0.15 s background transition, which first gave false 1:1 results.
- **Unmatched hovers:** 7-9% of hovers didn't match. These were first and last rows still scrolling, where the pointer landed on a neighbouring ledger row. That row is measured in its own turn.
- **Limit:** the method doesn't read pixels, so text over the glow still relies on the developer's pixel tool, as in r1.
