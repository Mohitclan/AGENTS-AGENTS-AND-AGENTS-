## Lessons recorded

- marketing: hooks, audience lines and feature ranges count as claims. A range shown next to a trial call to action names the trial limit, and a missing feature is never followed by "yet". (from r1 fixes 1-3, 6)
- marketing: in self-review, check the call to action against the fact sheet's exact wording, and open a page before describing what it shows. (from r1 fixes 4, 5, 8)
- main memory: when a request asks for more items than the allowed source holds, deliver what the source has plus labelled gap rows. Never stretch a near-match to hit the count.
- `lint-copy mine`: `unsourced-number` repeats (11 times in 5 files), but not from this task, which had 0 fails. It is already in marketing's memory, and a board suggestion about counting mid-write saves covers it. No new step on the ladder.
- One small slip, no lesson added: marketing's last report said its edit had shifted line numbers by two, but grep showed it hadn't. The existing coordinator lesson (grep before trusting a report) caught it.
